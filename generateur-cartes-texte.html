# 🚀 Guide Rapide - Générateur de Cartes PDF Pro ## 📥 NOUVEAU : Téléchargement du modèle intégré ! L'application intègre maintenant un **bouton de téléchargement direct** du modèle Excel. ### 📍 Où le trouver ? 1. Ouvrez `generateur-cartes-pro.html` 2. Cliquez sur l'onglet "📊 Import CSV/Excel" 3. En haut des instructions, vous verrez un **encadré vert** avec : - 📥 "Téléchargez le modèle Excel" - Bouton "⬇️ Télécharger le modèle" --- ## 🎯 Workflow complet en 4 étapes ### Étape 1️⃣ : Télécharger le modèle ``` 1. Cliquez sur le bouton "⬇️ Télécharger le modèle" 2. Le fichier se télécharge : modele_cartes.xlsx 3. Il contient 10 défis sur l'IA (exemple) ``` **Source du modèle** : https://silverteacher.github.io/Drane/defis_ia_cartes.xlsx ### Étape 2️⃣ : Modifier le modèle ``` 1. Ouvrez modele_cartes.xlsx dans Excel/LibreOffice 2. Modifiez les colonnes : - Texte_Recto : Vos propres textes - Taille_Police : 8-18 (ou vide pour défaut) - Couleur : Code hex (ou vide pour défaut) 3. Enregistrez vos modifications ``` **Structure attendue** : ``` | Texte_Recto | Taille_Police | Couleur | |--------------------------|---------------|----------| | Votre texte de carte 1 | 12 | #1e293b | | Votre texte de carte 2 | 14 | #ff0000 | | ... | ... | ... | ``` ### Étape 3️⃣ : Importer dans l'application ``` 1. Dans l'onglet "Import CSV/Excel" 2. Section "1️⃣ Sélectionner le fichier CSV/Excel" 3. Choisissez votre fichier modifié 4. Message : "Fichier chargé ! X carte(s) détectée(s)" ``` ### Étape 4️⃣ : Ajouter une image (optionnel) Deux options au choix : #### Option A : Image locale ``` 1. Section "2️⃣ Image pour toutes les cartes" 2. "Option A : Image locale" 3. Cliquez et sélectionnez votre image ``` #### Option B : URL d'image ``` 1. Section "2️⃣ Image pour toutes les cartes" 2. "Option B : URL d'image" 3. Collez l'URL (ex: Pixabay) ``` **Exemple d'URL Pixabay** : ``` https://pixabay.com/get/[ID-image]/download?force=true ``` **OU laissez vide** pour des cartes sans image au verso. ### Étape 5️⃣ : Importer et générer ``` 1. Cliquez "📥 Importer les cartes" 2. Attendez (surtout si URL) 3. Vos cartes apparaissent dans l'onglet "Création manuelle" 4. Cliquez "📄 Générer le PDF avec repères de découpe" 5. Imprimez en recto-verso ! ``` --- ## 🎨 Personnalisation avancée ### Couleurs disponibles Voici quelques codes couleur à utiliser dans la colonne `Couleur` : | Couleur | Code Hex | Usage recommandé | |---------|----------|------------------| | Noir | `#1e293b` | Texte standard | | Bleu foncé | `#1e40af` | Titres | | Vert | `#059669` | Positif/succès | | Rouge | `#dc2626` | Important/attention | | Orange | `#ea580c` | Avertissement | | Violet | `#7c3aed` | Créativité | | Cyan | `#0891b2` | Information | ### Tailles de police | Taille | Usage recommandé | |--------|------------------| | 8-10 | Texte très long (>100 mots) | | 11-12 | Texte standard (défaut) | | 14-16 | Titres courts | | 18 | Mots-clés uniques | --- ## 💡 Exemples d'utilisation ### Exemple 1 : Cartes de vocabulaire **Modèle modifié** : ```csv Texte_Recto,Taille_Police,Couleur Artificial Intelligence (AI),16,#1e40af Machine Learning (ML),16,#059669 Deep Learning (DL),16,#7c3aed ``` **Image** : Icône cerveau ou robot **Résultat** : 3 cartes de vocabulaire anglais-français ### Exemple 2 : Défis pédagogiques **Modèle modifié** : ```csv Texte_Recto,Taille_Police,Couleur "DÉFI 1 : Créez un quiz interactif avec l'IA",12,#1e293b "DÉFI 2 : Générez une image pour illustrer un concept",12,#059669 "DÉFI 3 : Analysez un texte avec un outil d'IA",12,#dc2626 ``` **Image** : Logo IA ou Pixabay **Résultat** : Cartes de défis pour formation ### Exemple 3 : Flashcards mathématiques **Modèle modifié** : ```csv Texte_Recto,Taille_Police,Couleur Quelle est la dérivée de x² ?,14,#1e293b Résoudre : 2x + 5 = 15,14,#1e293b Calculer : 15% de 200,14,#1e293b ``` **Image** : Symboles mathématiques **Résultat** : Flashcards d'entraînement --- ## 🔧 Astuces et conseils ### ✅ Bonnes pratiques 1. **Testez d'abord** avec le modèle fourni avant de créer le vôtre 2. **Gardez les en-têtes** exactement comme dans le modèle 3. **Utilisez des guillemets** pour les textes longs dans CSV 4. **Vérifiez les codes couleur** (toujours commencer par #) 5. **Compressez les images** si elles sont trop lourdes ### ⚠️ Erreurs courantes ❌ **Colonnes mal nommées** ```csv Texte,Police,Color ← INCORRECT Texte_Recto,Taille_Police,Couleur ← CORRECT ``` ❌ **Couleur sans #** ```csv 1e293b ← Peut ne pas fonctionner #1e293b ← CORRECT ``` ❌ **Taille de police invalide** ```csv large ← INCORRECT 14 ← CORRECT ``` ### 🎯 Optimisation **Pour des fichiers volumineux** : - Limitez à 50-100 cartes par import - Utilisez des images compressées (<500 KB) - Préférez JPG à PNG pour les photos **Pour la qualité d'impression** : - Résolution image minimale : 640×480 - Résolution recommandée : 1280×720 - Format de carte : 63×88 mm (standard poker) --- ##
