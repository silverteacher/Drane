📊 Importer depuis CSV/Excel

📝 Instructions pour l'import

  1. Format du fichier : CSV ou Excel (.xlsx, .xls)
  2. Colonnes requises :
    • Texte_Recto : Le texte à afficher au recto (obligatoire)
    • Taille_Police : Taille de la police en points (8-18, défaut: 12)
    • Couleur : Couleur du texte en hexadécimal (ex: #1e293b ou 1e293b)
    • Image_Verso : Nom du fichier image pour le verso (ex: image1.jpg)
  3. Valeurs par défaut : Si une cellule est vide, les valeurs par défaut seront utilisées
  4. Images : Après avoir importé le CSV/Excel, sélectionnez les images correspondantes

💡 Exemple de fichier CSV

Texte_Recto,Taille_Police,Couleur,Image_Verso
Carte numéro 1,12,#000000,image1.jpg
Carte numéro 2,14,#ff0000,image2.jpg
Carte numéro 3,10,,
Sans image,,#0000ff,
